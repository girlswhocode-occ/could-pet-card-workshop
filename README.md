# ☁️🐾 Cloud Pet Card Workshop

Welcome to the Girls Who Code Cloud Pet Club!

Today, you will design, build, and publish your own
virtual pet card using HTML, UI/UX design principles,
and cloud hosting.

Your mission is to bring your virtual pet to life
by writing your own HTML code!

No previous coding experience is required. 💗

## 🎯 Learning Objectives

By the end of this workshop, you will be able to:

- Write HTML elements from scratch.
- Use opening and closing tags.
- Work with HTML attributes and classes.
- Organize content using nested elements.
- Apply fundamental UI/UX design principles.
- Publish a website using GitHub Pages.

## 🚀 Getting Started

1. Click **Use this template**.
2. Select **Create a new repository**.
3. Give your repository a unique name.
4. Set your repository visibility to Public.
5. Create your repository.
6. Press the period (.) key to open GitHub.dev,
   or open your project in local VS Code.
7. Open index.html.
8. Follow the missions below!

## 📁 Project Files

- `index.html` — Your HTML coding workspace.
- `style.css` — Prepared styles and color themes.
- `README.md` — Your workshop instructions.

You only need to edit `index.html` today.
The CSS is already prepared for you!

## 🎨 Mission 1: Choose Your Theme

Find the main element in your HTML file.

Choose a color theme that matches your pet's personality.

Available themes:

- 🌸 pink
- 💜 lavender
- 🌿 mint
- 🫧 blue
- 🍑 peach

Keep the `pet-card` class and replace `pink`
with your preferred theme.

**HTML concept:** Attributes and classes

**Design concept:** Color harmony

## 🏷️ Mission 2: Create Your Card Header

Create a header for your pet card.

Requirements:

- Use a `header` element.
- Give it the class `card-header`.
- Add two `span` elements inside the header.
- Include a club name and a unique card number.

**HTML concept:** Semantic elements and nesting

**Design concept:** Alignment and consistency

## 🐣 Mission 3: Adopt Your Pet

Choose your favorite animal and create an avatar.

Animal inspiration:

🐱 🐶 🐰 🐸 🐼 🦊 🐧 🐻 🐹 🐉

Requirements:

- Create a `div` element.
- Give it the class `pet-avatar`.
- Place your animal emoji inside the container.

**HTML concept:** Containers and attributes

**Design concept:** Visual focus

## 🎀 Mission 4: Give Your Pet a Name

Every pet needs a unique identity!

Requirements:

- Create an `h1` element.
- Write your pet's name inside it.
- Remember both opening and closing tags.

**HTML concept:** Headings

**Design concept:** Visual hierarchy

## 💬 Mission 5: Introduce Your Pet

Tell us a little about your virtual pet.

Requirements:

- Create a paragraph with the class `pet-type`.
- Create another paragraph with the class `description`.
- Write a short and creative introduction.

Think about:

- What kind of pet is it?
- Where does it come from?
- What makes it special?

**HTML concept:** Paragraphs and classes

**Design concept:** Readability and clear communication

## ✨ Mission 6: Create Your Pet's Information

Let's give your pet a personality!

Create a `section` element with the class `details`.

Inside this section, create at least three
information groups.

Suggested categories:

- 💗 Personality
- 🍓 Favorite Food
- ✨ Special Ability

Each information group should contain:

1. A `div` with the class `detail`.
2. A `span` with the class `detail-icon`.
3. Another `div` containing:
   - An `h2` heading.
   - A `p` paragraph.

### Structure Hint

    section (details)
    ├── div (detail)
    │   ├── span (detail-icon)
    │   └── div
    │       ├── h2
    │       └── p
    ├── div (detail)
    └── div (detail)

Try writing the HTML yourself using this structure.

Make sure every element is properly nested
and every required closing tag is included.

**HTML concept:** Sections, containers, and nesting

**Design concept:** Consistency, proximity, and organization

## 💌 Mission 7: Sign Your Creation

Give yourself credit for your amazing work!

Requirements:

- Create a `footer` element.
- Include your name or nickname.
- Add a creative message if you like.

**HTML concept:** Semantic HTML

| Element | Purpose |
|---|---|
| `<h1>` | Main heading |
| `<h2>` | Section heading |
| `<p>` | Paragraph |
| `<div>` | Generic container |
| `<span>` | Inline container |
| `<header>` | Introductory content |
| `<section>` | Related content |
| `<footer>` | Footer content |
| `<img>` | Image |
| `<a>` | Hyperlink |
| `<ul>` | Unordered list |
| `<ol>` | Ordered list |
| `<li>` | List item |
| `<strong>` | Important text |
| `<em>` | Emphasized text |

| Attribute | Purpose |
|---|---|

## ☁️ Send Your Pet to the Cloud

It's time to publish your website!

### Step 1: Save Your Changes

Save your HTML file.

### Step 2: Commit and Push

Open Source Control in your editor.

Write a commit message, such as:

    Created my cloud pet card

Commit your changes.

If you are using local VS Code, push or sync
your changes to GitHub.

### Step 3: Open Repository Settings

Return to your GitHub repository and click Settings.

### Step 4: Select Pages

Find Pages in the settings sidebar.

### Step 5: Configure Deployment

Under Build and deployment, select:

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Click Save.

### Step 6: Visit Your Website

Wait a few minutes for deployment to finish.

Refresh the Pages settings and click Visit site.

Your website URL should look like:

    https://USERNAME.github.io/REPOSITORY-NAME/

Open your website on your phone to test
its responsive design!

## 🔧 Troubleshooting

### My styles are not showing.

- Check your class names.
- Make sure style.css exists.
- Check the stylesheet link in index.html.

### My layout looks strange.

- Check for missing closing tags.
- Make sure your elements are properly nested.
- Check that your content is inside the main container.

### My website is not updating.

- Make sure your changes are committed to GitHub.
- Check the Actions tab for deployment status.
- Wait a few minutes and refresh your website.
